# awa5.0_to_text
This code converts awatalk to readable text,
it can not differ between integers and awascii and thereby prints both as integers
Please enter the entire Awatalk with the initial 'awa'

Example awatalk: awa awa awawa awawa awa awa awawawa awa awawa awa awawa awawa awa awa awa awa awawa awa awa awawawa awawa awa awa awawa awa<br/>
Example awatalk output: 100<br/>
